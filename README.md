# How to use vite (Visual Studio Code is recommended)
1. Install Node.js and npm
2. Download mapway folder
3. In mapway folder -> (in terminal) npm install, then npm update
4. To run the project test -> (in terminal) npm run dev -> Go to localhost:port (Click the link it gives you)
5. Close with enter+q
